# 2026-08-21 EDA の再現手順と読み方

Kaggle ノートブック `osakanateishoku/20260821-eda` の内容を、保存可能な表・図・DICOM代表画像を生成するスクリプトへ移植した。実行コードは `scripts/run_eda.py`、分析本体は `src/rsna2026/eda.py` である。乱数種は既定で42であり、代表例とDICOMヘッダの標本抽出を再現できる。

## 実行方法

ローカルのリポジトリから、次を実行する。入力は読み取り専用の `/kaggle/input`、出力は取得可能な `/kaggle/working/outputs` のみを使用する。

```bash
./scripts/run-eda.sh
```

このコマンドはEDA用Kaggleノートブックを送信して完了まで待ち、成果物をローカルの `outputs/eda/` へ取得する。Kaggleノートブック内で分析本体だけを実行するときは次のとおり。

```bash
python scripts/run_eda.py --output-dir /kaggle/working/outputs/eda
```

別の入力マウントを明示するときは、`--data-root /kaggle/input/…` を指定する。DICOMヘッダの走査は既定で200系列に制限される。必要なら `--metadata-series`、代表系列の表示枚数は `--image-slices` で変更できる。

## 出力内容

`tables/` に集計CSV、`figures/` に分布・相関・構成グラフ、`images/` にDICOMの代表パネルを保存する。報告書の標本は最大5件・先頭1000文字に限り、`tables/sample_reports.csv` に出力するため、共有時は患者情報を含み得るデータとして扱う。

主な確認対象は次のとおりである。

- `overview.csv` と `series_per_study.png`：検査単位と系列単位の対応、検査当たりの系列数。
- `label_statistics.csv`、`known_label_counts.png`、`label_prevalence.png`、`label_correlation.png`：十二所見のラベル欠損、陽性率、完全ラベル検査、所見間の相関。相関は全十二ラベルが揃う検査だけで算出する。
- `plane_counts.png`、`plane_sequence.png`、`plane_slot_coverage.csv`：矢状・冠状・横断面と、液体感受性・脂肪抑制の組合せ。選択する系列スロットの網羅率と重複率を確認する。
- `report_lengths.png`、`report_scripts.png`：放射線科報告の長さと言語文字種。報告が大量にあり専門家ラベルが欠ける構造は、弱ラベル化の検討根拠になる。
- `sampled_dicom_metadata.csv`、`dicom_slice_counts.png`、`matrix_sizes.png`、`slice_thickness.png`、`manufacturers.png`：最大200系列のDICOMヘッダ標本に基づく撮像枚数、行列サイズ、スライス厚、装置の分布。これは全データの厳密な分布ではない。
- `sample_series.png`、`three_plane_study.png`、`positive_*.png`：一系列の等間隔スライス、三断面の代表系列、四所見の陽性検査の代表断面。DICOM表示は各画像の1・99パーセンタイルで正規化しており、学習前処理ではない。

## 分析から得る設計上の示唆

データは「検査 → 複数系列 → 複数スライス」という階層構造で、報告と十二所見ラベルは検査単位に付く。したがって、単一画像の分類ではなく、スライスから系列表現を作り、断面・系列を統合して検査単位で多ラベル推定する問題として扱う。

完全な専門家ラベルを持つ検査が限られるかを `label_statistics.csv` で必ず確認する。少ない場合は、報告からの弱ラベル生成、検査単位の交差検証、断面・撮像条件を用いた系列選択、二・五次元または系列単位の集約を順に検討する。DICOM標本の分布は、リサイズ、等間隔抽出、撮像条件の扱いを決めるための根拠として使う。
