# 公開順位表0.92へ向けた本質的改善案

作成日: 2026年9月4日

## 1. 目的

本メモは、提出0013の公開スコア0.881を基準に、公開順位表で0.92程度へ到達するために
現行実装をどのように変えるべきかを整理する。学習率、世代数、欠落率などの微調整ではなく、
次の本質的な改善を対象とする。

- 膝MRIの解剖学と所見定義を反映した入力設計
- DICOM幾何、系列選択、強度正規化の改善
- 密なスライス表現と所見別集約
- 競技の判定基準に合わせた弱ラベル品質向上
- 未ラベル画像を使ったMRI固有の事前学習
- 少数の正式ラベルを過適合させない検証と最終学習

関連する詳細は
[`weak-label-and-validation-strategy.md`](weak-label-and-validation-strategy.md) と
[`mri-data-processing-research.md`](mri-data-processing-research.md) に記録されている。本メモでは、
最新の提出結果を踏まえて実行順序を定める。

## 2. 結論

現在の最大の問題は模型の大きさではなく、MRI検査の情報を模型へ渡す前後で失っていることに
ある。特に次の三点が大きい。

1. 一系列を三枚窓へ分割して独立に予測し、最後に確率平均している。
2. 左右、解剖学的位置、系列品質を使わず、各撮像枠で枚数最大の一系列だけを選んでいる。
3. 弱教師が「競技の画像判定基準を満たす確率」ではなく、「臨床レポートに診断が書かれた
   確率」に近い。

最初に取り組むべき変更は、336画素と130 mm視野を固定したまま、左右統一、系列再分類、
全範囲の密な窓入力、所見別の窓集約を導入することである。その後に弱教師、解剖学的局所像、
MRI固有の事前学習を改善する。

## 3. 現状のボトルネック

### 3.1 弱教師より画像模型が大幅に弱い所見がある

提出0013の分割外平均AUCは0.82419である。一方、現在使っている公開弱教師は正式58件に
対して0.89271である。同じ正式58件に対する所見別の値を比べると、構造病変で大きな差がある。

| 所見 | 弱教師AUC | 画像模型AUC | 画像模型と教師の差 |
|---|---:|---:|---:|
| ACL | 0.98713 | 0.87010 | -0.11703 |
| MCL | 0.96825 | 0.79365 | -0.17460 |
| 内側半月板 | 0.94832 | 0.78125 | -0.16707 |
| 外側半月板 | 0.87888 | 0.69814 | -0.18075 |
| 内側区画変形性関節症 | 0.93178 | 0.94264 | +0.01085 |
| 外側区画変形性関節症 | 0.83269 | 0.72534 | -0.10735 |
| 膝蓋大腿区画変形性関節症 | 0.90154 | 0.74646 | -0.15508 |
| 関節液 | 0.87702 | 0.91677 | +0.03975 |
| 滑膜炎 | 0.79032 | 0.74552 | -0.04480 |
| ベーカー嚢胞 | 0.94384 | 0.96377 | +0.01993 |
| 骨挫傷 | 0.85965 | 0.86910 | +0.00945 |
| 急性骨折 | 0.79306 | 0.83750 | +0.04444 |
| 平均 | **0.89271** | **0.82419** | **-0.06852** |

ACL、MCL、両半月板、外側区画および膝蓋大腿区画の変形性関節症では、まず画像表現を
改善しなければ弱教師の改善を模型性能へ変換できない。逆に関節液、ベーカー嚢胞、骨挫傷、
急性骨折は画像模型が教師を上回っており、教師雑音の影響を受けながら画像から有効な順位を
学べている可能性がある。

### 3.2 現行の集約は局所病変を薄める

現行実装は各撮像枠の連続三枚を三チャンネル画像としてDINOv2へ入力する。学習時は十二枚から
非重複の三枚窓を一つ選び、推論時は十個の重なり窓を独立に予測して確率平均する。模型は一度の
前向き計算で一系列全体を見ない。

これは次の競技定義と相性が悪い。

- 半月板断裂は、表面へ達する異常信号が二画像以上にあるか、形態異常があることを判定する。
- ACLとMCLは、軽度信号変化ではなく高度な線維断裂と周辺所見を判定する。
- 骨折、骨挫傷、半月板断裂は少数スライスだけに現れることがある。
- 変形性関節症、関節液、滑膜炎は局所最大反応だけでなく、範囲や広がりが重要である。

局所病変へ単純平均を使うと、正例となる少数窓が多数の正常窓に薄められる。

### 3.3 系列枠の欠損が多すぎる

選択記録では、4,407検査のうち次の枠が欠損扱いになっている。

| 撮像枠 | 欠損検査数 | 欠損率 |
|---|---:|---:|
| 矢状断・液体強調・脂肪抑制あり | 288 | 6.5% |
| 冠状断・液体強調・脂肪抑制あり | 197 | 4.5% |
| 軸位断・液体強調・脂肪抑制あり | 64 | 1.5% |
| 矢状断・液体強調・脂肪抑制なし | 1,647 | 37.4% |
| 冠状断・T1 | 1,580 | 35.9% |
| 矢状断・T1 | 2,595 | 58.9% |

構造強調系列をT1へ限定した分類が厳しすぎる可能性が高い。また、24,371系列のうち2,582系列が
どの枠にも割り当てられていない。欠損マスク自体は正しくても、有効な系列を誤って捨てれば模型へ
情報は渡らない。

### 3.4 固定中心と一枚単位正規化に限界がある

130 mm固定物理視野は公開スコアを0.868から0.879へ改善し、336画素化で0.881となったため、
物理寸法を揃える方向は維持する価値がある。ただし、現行処理には次の限界がある。

- 解剖学的な膝中心ではなく画像中心を使う。
- 全断面、全所見へ同じ130 mmを使う。
- 左右を同じ向きへ統一しない。
- 各画像を個別に1・99百分位正規化し、系列内の信号関係を残さない。
- 面内画素間隔は使うが、スライス間の物理間隔を固定しない。

## 4. 優先順位1: 密な全窓・所見別多重例学習

### 4.1 推奨構造

一検査を次の階層で表現する。

```text
検査
  └─ 複数系列
       └─ 物理座標順に並べた全スライス
            └─ 連続三枚窓の特徴
                 └─ 系列内の所見別集約
                      └─ 断面・撮像条件間の所見別集約
                           └─ 十二所見
```

各窓へ次の補助情報を付ける。

- 断面
- 撮像条件
- 系列識別子
- 系列内の相対位置
- 患者座標上の物理位置
- 左右
- 面内画素間隔とスライス間隔
- 系列品質

系列内集約は所見群で変える。

| 所見群 | 初期集約方式 | 理由 |
|---|---|---|
| ACL、MCL | 上位二窓平均または滑らかな最大値 | 断裂と浮腫が限られた断面に現れる |
| 内側・外側半月板 | 上位二～三窓平均 | 二画像以上という判定基準を近似する |
| 骨挫傷、急性骨折 | 上位窓平均 | 小さな局所病変を平均で消さない |
| ベーカー嚢胞 | 後内側領域に事前分布を持つ注意集約 | 特徴的な位置に生じる |
| 関節液、滑膜炎 | 広域注意集約 | 広がりと複数部位の情報が必要 |
| 三区画の変形性関節症 | 区画別注意集約 | 部位と病変範囲を同時に評価する |

単に推論後の平均を最大値へ置き換えるのではなく、模型が全窓の特徴を同時に見て検査単位の
ロジットを出す構造にする。

### 4.2 所見別の撮像枠事前分布

注意機構を完全に自由に学習させず、医学的に妥当な初期事前分布を与える。

| 所見 | 優先する断面・系列 |
|---|---|
| ACL | 矢状断液体強調を主、冠状断を補助 |
| MCL | 冠状断液体強調を主 |
| 両半月板 | 矢状断と冠状断の液体強調・構造強調 |
| 内側・外側区画変形性関節症 | 冠状断構造強調を主、矢状断を補助 |
| 膝蓋大腿区画変形性関節症 | 軸位を主、矢状断を補助 |
| 関節液、滑膜炎 | 軸位と矢状断液体強調 |
| ベーカー嚢胞 | 矢状断液体強調 |
| 骨挫傷 | 三断面の脂肪抑制液体強調 |
| 急性骨折 | 三断面の液体強調と構造強調 |

この事前分布は固定マスクではなく、学習可能な注意得点へ弱い加算値として入れ、データが反証
できるようにする。

## 5. 優先順位2: DICOMの解剖学的正規化

### 5.1 左右の統一

`ImageOrientationPatient`、`ImagePositionPatient`、`PixelSpacing`、`Laterality`から膝の左右を
判定する。冠状断と軸位断を同じ患者向きへ反転し、模型から「内側が画像の右か左か」を学ぶ負担を
除く。DICOMタグと幾何判定が食い違う検査は監査対象として記録する。

### 5.2 物理座標への再標本化

現在の相対添字による十二枚抽出を、患者座標上の一定間隔への再標本化へ変更する。各系列で
次を保持する。

- スライス面法線上の物理位置
- 実際の撮像範囲
- 断面間隔
- 欠落または重複スライス

固定枚数が必要な場合も、相対添字ではなく一定の物理範囲から選ぶ。病変が端にある所見を考え、
中央20～80%を一律に捨てず、全範囲を保持した上で所見別注意に選ばせる。

### 5.3 解剖学的中心と多尺度入力

軽量な位置推定器で大腿骨顆、脛骨高原、膝蓋骨、顆間窩を検出し、画像中心ではなく解剖学的中心で
切り出す。入力は次の二尺度とする。

1. 130～150 mm程度の全体像
2. 半月板、顆間窩、膝蓋大腿関節などの局所高解像度像

全体像は関節液、ベーカー嚢胞、広範な骨髄病変を残し、局所像は小さな断裂や軟骨欠損を残す。

### 5.4 系列の再分類と複数系列保持

撮像枠をまず「断面 × 液体強調／構造強調」とし、T1、PD、T2、脂肪抑制方式は追加属性として
保持する。各枠で最大枚数の一系列だけを採らず、少なくとも上位二系列を候補にする。

系列品質は次で評価する。

- 面内解像度
- スライス厚と間隔
- 解剖学的な撮像範囲
- 信号対雑音比の近似値
- 動きや縞状アーチファクト
- 復号欠損率

品質値を使って一系列を決め打ちする方法と、複数系列を注意集約する方法を比較する。

### 5.5 系列単位の強度正規化

各画像を独立に正規化する代わりに、選択した系列または解剖学的領域の全画素から共通の2・98
百分位を計算する。これにより隣接スライス間の信号関係を保つ。装置差への頑健性を残すため、
次の二入力を併用する案もある。

- 系列全体で正規化した画像
- 一枚単位で局所コントラストを強調した画像

## 6. 優先順位3: 競技基準に合わせた弱教師

### 6.1 単一確率を作る前の構造化

各検査・各所見について、最低限次を保存する。

| 項目 | 内容 |
|---|---|
| 状態 | 明示的陽性、明示的陰性、不確実、言及なし |
| 重症度 | 軽度、中等度、高度、判定不能 |
| 時相 | 急性、慢性、陳旧性、判定不能 |
| 部位 | 内側、外側、膝蓋大腿、骨・靱帯内の詳細部位 |
| 大きさ・範囲 | 報告書から取得できる場合に保持 |
| 根拠 | 原文中の短い根拠箇所 |
| 言語 | 原文の言語 |
| 定義適合 | 競技の陽性閾値を満たす、境界、満たさない、判定不能 |
| 出典 | 使用した抽出器と版 |
| 不一致 | 複数抽出器間の不一致状態 |

### 6.2 競技の陽性基準への写像

- ACLは軽度信号変化や変性を陰性とし、高度部分断裂以上を陽性へ寄せる。
- MCLは低度捻挫、慢性・陳旧性変化を陽性へ含めない。
- 半月板は実質内変性と関節面へ達する断裂を分ける。
- 三区画の変形性関節症は、約1 cm以上かつ軟骨厚50%以上の欠損を基準にする。
- 関節液とベーカー嚢胞は少量を陰性寄り、中等量以上を陽性寄りにする。
- 骨挫傷は外傷性骨髄浮腫と変性・軟骨下浮腫を分ける。
- 急性骨折は急性皮質断裂・骨折線を中心とし、骨軟骨損傷、疲労骨折、陳旧性骨折を別状態にする。

### 6.3 言及なしを所見別に扱う

言及なしは陰性ではない。滑膜炎はレポートで省略されやすい一方、ベーカー嚢胞や内側区画
変形性関節症の省略は陰性を強く示す場合がある。したがって一律補完は行わない。

初期方針は次の通りとする。

- 滑膜炎だけ、言及なしセルを関節液などから弱く補完する候補を持つ。
- 明示記載は相関補完で上書きしない。
- その他の所見は補完を事前登録した個別実験として扱う。
- 正式58件を見ながら十二所見すべての規則を探索しない。

### 6.4 複数教師と画像による共同学習

公開教師、自前の決定規則、自前の多言語抽出器を独立に作り、次のように統合する。

- 全教師が一致するセルは通常重みで学習する。
- 教師が不一致のセルは重みを下げるか除外する。
- 全教師が言及なしのセルは初期段階では損失対象外にする。
- 改善後の画像模型が分割をまたいで安定して同じ予測を出す場合だけ、言及なしセルへ画像由来の
  補助教師を追加する。

画像由来教師は自分自身の予測をそのまま学習させず、各検査を学習に使っていない分割外模型から
生成する。レポート教師と画像教師の一致例を強くし、不一致例は監査対象にする。

## 7. 優先順位4: MRI固有の事前学習と所見群別模型

自然画像由来のDINOv2だけに依存せず、4,407検査すべてを使って次の自己教師課題を行う。

- マスクした画像区画またはスライスの復元
- 隣接スライス順序の予測
- 同一検査の異なる断面・撮像条件を対応付ける対照学習
- 同一解剖位置の異系列表現を近づける学習
- 同一系列内の近接スライスと遠隔スライスを区別する学習

微調整時は共有符号器の上に次の所見群別分岐を置く。

1. 靱帯・半月板
2. 三区画の変形性関節症
3. 関節液・滑膜炎・ベーカー嚢胞
4. 骨挫傷・急性骨折

各群で必要断面、視野、窓集約方式が異なる。完全な十二模型に分ける前に、四群で共有と専門化の
均衡を取る。

## 8. 公開0.936実装から得られる示唆

公開スコア0.936を記録した公開ノートブックでは、主に次の要素が組み合わされている。

- DINOv2による広域表現
- 放射線画像事前学習済みResNet-50
- 全検査範囲の密な窓を集約するCoAtNet系模型
- 所見別の撮像枠事前分布
- 左右の幾何判定
- 重複系列の救済
- 所見別百分位順位統合

同ノートブック内の記録では、学習対象を3,155件から4,349件へ拡大したCoAtNet模型で正式58件の
AUCが0.8923から0.9054へ改善し、外側半月板、急性骨折、外側区画変形性関節症、内側半月板、
ACLで大きく改善したとされる。また、局所専門模型を追加した版は公開0.936から0.935へ低下した。

ここから得るべき結論は、公開実装を丸ごと複製することではない。

- 全範囲の密な検査表現には価値がある。
- 所見別の入力・集約が必要である。
- 相関の低い表現の統合は有効だが、専門模型の追加が常に改善するわけではない。
- 最終学習で全4,349弱ラベル検査を戻す価値がある。
- 複合実装の公開スコアだけでは各要素の因果効果を分離できない。

## 9. 推奨する実験順序

### 第1段階: 入力監査

学習を行う前に次を集計・可視化する。

1. 撮像枠別の欠損率と未割当系列の内訳
2. 左右タグと幾何判定の一致率
3. 各系列の物理撮像範囲、断面間隔、面内解像度
4. 枠ごとに最大枚数系列と最高品質系列が一致する割合
5. 正式58件と装置指紋別標本に対する全選択スライスのモンタージュ

この段階の目的は模型性能ではなく、模型へ意図したMRIが渡っていることの確認である。

### 第2段階: 最優先の画像模型

次を一つの設計変更として実装する。

- 336画素、130 mmを維持
- 左右を統一
- 断面 × 液体強調／構造強調へ再分類
- 有効な全範囲を密な三枚窓として保持
- 物理位置埋め込みを追加
- 所見別の上位窓・注意集約を導入
- 医学的な撮像枠事前分布を追加

これは「模型を大きくする」実験ではなく、現在捨てている検査情報を保持する実験である。

### 第3段階: 解剖学的多尺度入力

第2段階を基準に、解剖学的中心と局所高解像度像を追加する。全体像と局所像を同時に使い、
半月板・靱帯・軟骨の局所病変と、関節液・嚢胞・骨髄病変の広域所見を両立させる。

### 第4段階: 弱教師の置換

画像処理を固定してから、三値以上の構造化教師、競技基準への写像、教師間不一致重みを導入する。
画像と教師を同時に変更しない。

### 第5段階: MRI自己教師学習

第2～4段階で確定した入力を使い、全4,407検査で事前学習してから同じ分割へ微調整する。

### 第6段階: 最終学習と相補的統合

構成と学習世代を固定した後、内側検証へ置いた弱ラベル検査も戻し、各模型を全4,349件で再学習
する。異なる自然画像符号器を増やすより、放射線画像事前学習模型や異なる検査集約方式など、
誤りの相関が低い模型だけを所見別順位で統合する。

## 10. 実験の昇格条件

正式58件は非無作為で標本数も少ないため、単一の平均AUCだけで昇格させない。

- 固定した正式58件の分割外予測を必ず保存する。
- 基準模型との対応付き再標本化区間を計算する。
- 平均だけでなく所見別AUCを確認する。
- 主要仮説が対象とする所見群で改善していることを要求する。
- 弱教師の内側検証だけが改善し、正式分割外評価が悪化する案は採用しない。
- 公開順位表は最終確認に使い、細かな構成探索へ使わない。
- 同じ提出へ単調変換後に再順位化するだけの変更は、AUCの順位を変えないため実験対象にしない。

当面の昇格基準として、平均AUC差が小さい場合でも、狙った所見群のうち多数が同方向へ改善し、
重大な悪化所見がないことを求める。正式58件の信頼区間が広いため、一回の0.005程度の変化を
確定的な改善と扱わない。

## 12. 当面やらないこと

- DINOv2-smallを単純に大型版へ置き換える。
- 解像度だけをさらに上げる。
- 全所見へ同じ最大値集約を使う。
- 全所見の言及なしを他所見から一律補完する。
- 正式58件に対して多数の統合重みや規則を探索する。
- 公開順位表だけを基準に視野、閾値、融合重みを細かく調整する。
- 相関の高い模型を本数だけ増やす。

## 13. 最初の推奨実験

次の正式候補は、提出0013を基準に以下だけを変更する。

> 左右統一、断面 × 液体強調／構造強調の系列再分類、全物理範囲の密な三枚窓、物理位置付きの
> 系列内注意集約、所見別の上位窓集約、所見別撮像枠事前分布。

弱教師、336画素、130 mm、画像拡張、DINOv2-small、正式4分割は固定する。この実験で
ACL、MCL、両半月板、外側区画・膝蓋大腿区画変形性関節症の教師との差を縮められるかを確認する。
改善が確認できてから、解剖学的局所像と弱教師刷新へ進む。
