# 学習画像前処理キャッシュ

作成日: 2026年9月9日

## 目的

撮像枠の再分類や学習を行うたびに学習画像のDICOM復号を繰り返さないよう、撮像枠判定から
独立した224画素の前処理画像キャッシュを作成する。これは正式提出ではなく、後続実験用の
入力生成である。

## 処理

- 対象: `train.csv` の全4,407検査、`train_series.csv` の全24,371系列
- 分割: `SHA-256(StudyInstanceUID) mod 4`
- 系列選択: 撮像枠へ分類せず全系列を保持
- 窓選択: DICOM患者座標順の隣接三枚窓を物理的に等間隔で最大十窓
- 画像選択: 各系列の窓に含まれるDICOMの和集合を一度だけ復号
- 前処理: 中央130 mm、1・99百分位正規化、`MONOCHROME1`反転、224画素双線形補間
- 保存: 検査単位の8ビット可逆圧縮配列と、撮像条件・物理窓情報を含むマニフェスト
- 容量上限: 一分割18 GiB。超過時は明示的に失敗する

## 整合性確認

- 四分割の検査集合は互いに排他的で、和集合は4,407検査と一致した。
- 全検査識別子集合のSHA-256は
  `72bb18659cba9fc84f4f363c2585f1a99f84e6f03971e4d8313813ba647aa81e`で、既存記録と一致した。
- 四マニフェストは前処理版、224画素、分割数4を共有している。
- 全665,954選択経路が、検査単位圧縮配列の相対経路へ一意に対応した。
- 各検査で、復号成功数と失敗数の和が保存画像数と一致した。
- Kaggle上に各マニフェストと検査単位の圧縮配列が保存されたことを出力一覧で確認した。
- 局所では `./scripts/verify.sh` と全102単体試験が成功した。

## 再実行

```bash
./scripts/verify.sh
./scripts/run-image-cache.sh
```

画像本体は端末へ取得せず、後続の学習ノートブックから四つの版付きノートブック出力を直接
入力として搭載する。
