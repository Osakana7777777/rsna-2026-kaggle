# 読影レポート由来の弱ラベルと検証設計

作成日: 2026年8月25日

## 1. 目的と結論

本メモは、4,407検査のうち正式な画像所見ラベルが58検査にしかなく、残る4,349検査には
読影レポートだけがあるという条件で、次の二点を整理する。

1. 読影レポートから、どのように高品質な弱ラベルを作るか。
2. 58件の正式ラベルを、学習、モデル選択、性能推定へどう配分するか。

先に結論を示す。

- 現時点では、公開済みの `llm_labels_v4_blend.csv` を凍結した基準教師として使うのが
  最も費用対効果が高い。正式58件に対する十二所見平均AUCは0.89271であり、単純な規則
  抽出より明らかに強い。ただし、これは「レポートを正しく読める度合い」ではなく、
  「画像を直接判定した正式ラベルへどれだけ近いか」で評価する必要がある。
- 自前ラベルは公開ラベルを捨てて一から作るのではなく、公開教師、決定的な医学規則、
  自前の多言語言語モデルの三者を比較・混合する。各所見を同じ方法で処理せず、
  「陽性」「陰性」「不確実」「記載なし」を分け、所見別に扱いを決める。
- 全4,407件を人手で読む必要はない。まず正式58件を全件監査し、その後は言語、所見、
  確信度、教師間不一致、記載なしを層化した約300検査を監査する。総数より、誤りやすい
  境界例を意図的に含めることが重要である。
- 58件を単一の保留集合へ分ける案は採らない。主評価は、報告文重複を同一群にした
  多ラベル層化5分割とし、五つの保留部分から得た予測を58件へ結合してから十二所見平均
  AUCを一度だけ計算する。各分割のAUCを単純平均してはならない。
- 弱ラベル部分は、損失や教師再現性、前処理不具合、学習停止時点の確認には使えるが、
  正式ラベルに対する画像性能の主検証集合にはできない。
- 58件へ何度も適合する危険を抑えるため、固定した主5分割、患者単位の対応付き再標本化
  区間、別の分割乱数種による感度解析を併用する。平均AUCの差が0.02未満なら、原則として
  未決着と扱う。

## 2. 競技固有の前提

正式ラベルはレポートから抽出されたものではない。主催者によれば、各検査を筋骨格系を
専門とする放射線科医二名が独立に読影し、不一致を第三の放射線科医が裁定した画像由来の
合意ラベルである。曖昧または境界上の所見は陰性とし、例えば関節液とベーカー嚢胞は
中等量以上、前十字靱帯と内側側副靱帯は高度部分断裂以上を陽性とする
([主催者による所見定義](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733343))。

したがって、臨床レポートに「軽度関節液」「低度捻挫」「軟骨症」と書かれていても、
競技ラベルでは陰性になり得る。逆に、画像上は存在するが臨床上の主訴と関係が薄く、
レポートで省略された所見も正式ラベルでは陽性になり得る。

実際に、参加者が正式58件から20件、合計240セルを人手監査したところ、レポートの明示的な
記載と正式ラベルの一致率は82.5%だった。主催者は不一致を想定内としており、レポートと
画像ラベルが食い違う場合は画像ラベルを正とすると回答している
([レポートと正式ラベルの不一致](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733826))。

この競技の弱ラベル作成は、単なる固有表現抽出ではない。次の二段階の推定である。

```text
多言語レポート
  └─ 記載内容の抽出
       └─ 競技の画像判定基準へ写像
            └─ 所見ごとの確率・不確実・記載なし
```

最初の段階を正しく行っても、二段階目で正式ラベルとずれる。この差を意識しないと、
非常に確信度の高い誤教師を作る。

## 3. 公開弱ラベルの現状

### 3.1 現在の基準教師

本リポジトリは `stevenleehans/rsna-knee-llm-report-labels` の
`llm_labels_v4_blend.csv` を固定ハッシュで使用している。正式58件に対する値は次のとおりで
ある。

| 所見 | 外部教師AUC |
|---|---:|
| ACL | 0.98713 |
| MCL | 0.96825 |
| 内側半月板 | 0.94832 |
| 外側半月板 | 0.87888 |
| 内側区画変形性関節症 | 0.93178 |
| 外側区画変形性関節症 | 0.83269 |
| 膝蓋大腿区画変形性関節症 | 0.90154 |
| 関節液 | 0.87702 |
| 滑膜炎 | 0.79032 |
| ベーカー嚢胞 | 0.94384 |
| 骨挫傷 | 0.85965 |
| 急性骨折 | 0.79306 |
| 平均 | **0.89271** |

この表から、前十字靱帯、内側側副靱帯、内側半月板、ベーカー嚢胞は比較的回収しやすく、
滑膜炎、急性骨折、外側区画変形性関節症は弱いことが分かる。すべての所見へ同じ損失重みを
与える根拠はない。

公開 Discussion の作成者報告では、単純な正規表現・語彙抽出は平均AUC 0.8136、
言語モデル読影は0.8780だった。さらに「記載なし」を0.5として明示したところ、全セルの
25.4%が記載なしだった。滑膜炎は83.7%が記載なしで、滑膜炎欄そのもののAUCは0.678だった
一方、関節液欄で滑膜炎を予測すると0.7115になった。滑膜炎が記載なしの場合だけ関節液から
補完すると滑膜炎は0.790、全体は0.8873へ改善したが、この補完を全所見へ広げると0.8805へ
悪化した
([「記載なし」も一つの状態](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733932))。

これは次を示す。

- 記載なしを陰性へ一律変換してはいけない。
- 滑膜炎の省略とベーカー嚢胞の省略は意味が異なる。
- 相関による補完は所見別に事前規則を定め、58件の結果を見ながら多数の組合せを探索しない。

### 3.2 公開ベースラインから得られる実務上の知見

2026年8月25日時点の公開情報では、DINOv2を使う公開ノートブックで0.81前後、公開された
推論ノートブックでは0.899や0.911の例が確認できる。Discussion では、単一分割モデルで
0.938、5分割集合で0.947、別参加者からはDINOv2単体0.915、5分割で0.929から0.942という
自己申告がある。ただし、これらは入力や教師を完全公開した同一条件の比較ではないため、
順位表の数値だけを再現可能な基準値とはみなさない
([単一モデルの公開スコア](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/735304)、
[公開ノートブックの一例](https://www.kaggle.com/code/romantamrazov/rsna-knee-dinosaur-v3))。

重要な共通知見は、単に符号器を大きくするより、教師、物理寸法、スライス順、切り出し、
入力解像度を改善する方が有望という点である。上位参加者の公開発言では、224画素でも
0.93台が報告される一方、392画素、150 mm中央切り出し、検査当たり32枚の無作為標本化を
使う例もある。つまり最適な画素数は確定していないが、「モデルが見る画像を人が確認し、
数mmの所見が残っているか確かめる」ことは共通して推奨されている。

DICOMメタデータだけの模型は、無作為5分割で0.6516、装置指紋で群分けすると0.5981まで
低下した。0.0534の差は施設・装置や報告様式の記憶を疑うべき大きさである
([DICOMメタデータ短絡の検証](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733517))。
弱ラベル4,349件の分割では、報告文重複だけでなく装置指紋による群分けも感度解析に含める。

## 4. 既存ラベルを使うか、自前で作るか

推奨は「公開教師を凍結した基準線として残し、自前教師は追加候補として作る」である。

### 4.1 公開教師を残す理由

- 4,407件すべてが揃い、確率値として提供されている。
- 正式58件に対する平均AUC 0.89271を本リポジトリで再確認済みである。
- 公開教師を変えなければ、画像処理や模型変更の比較で教師の変化が混入しない。
- 全件を自前の言語モデルで再処理する費用を、改善の見込みが分かるまで負わずに済む。

### 4.2 自前教師を作る価値

- 0.79前後の滑膜炎と急性骨折には改善余地がある。
- 公開混合値だけでは、元の根拠文、否定、不確実、記載なし、二つの教師の不一致が失われる。
- 競技定義に沿った所見別規則や確率校正を明示できる。
- 公開データセットの生成手順に依存しない再現可能性を確保できる。

### 4.3 推奨する自前教師の出力

各検査・各所見について、単一確率だけでなく次を保存する。

| 項目 | 内容 |
|---|---|
| 状態 | 陽性、陰性、不確実、記載なし |
| 確率 | 0から1の連続値 |
| 根拠 | 原文中の短い根拠箇所 |
| 言語 | 原文の言語 |
| 定義適合 | 競技の陽性閾値を満たす、境界、判定不能 |
| 出典 | 公開教師、自前規則、自前言語モデル |
| 不一致 | 教師間で状態または確率が食い違うか |

言語モデルには十二所見を一括で自由記述させず、固定した構造で出力させる。原文と翻訳の
両方を渡せる場合も、根拠は原文から抜き出させる。否定範囲、既往、術後、疑い、程度、
左右、別部位を区別する。温度は0、模型版、指示文、前処理、入力ハッシュを固定する。

### 4.4 所見別の初期方針

| 所見群 | 初期方針 |
|---|---|
| ACL、MCL | 低度捻挫や変性を陽性にせず、高度部分断裂以上へ寄せる |
| 半月板 | 変性信号と表面へ達する断裂を区別し、術後変化を不確実にする |
| 三区画の変形性関節症 | `osteoarthritis` だけでなく軟骨欠損、関節裂隙狭小化、骨棘、区画名を読む。軽度軟骨症は境界扱い |
| 関節液、ベーカー嚢胞 | 病名の有無ではなく量を読み、中等量以上へ高い確率を与える |
| 滑膜炎 | 明示記載は使う。記載なしは陰性にせず、関節液などからの補完を別版として比較する |
| 骨挫傷 | 外傷性の骨髄浮腫と変性・軟骨下浮腫を区別する |
| 急性骨折 | 急性皮質断裂・骨折線を中心にし、骨軟骨損傷、疲労骨折、陳旧性変化を不確実にする |

決定的な多言語語彙抽出は弱いが、監査用の第二教師として有用である。公開例では、単純な
語句一致0.638から、文単位の否定処理で0.667、変形性関節症の関連表現追加で0.727まで
改善した
([言語モデルを使わない弱ラベル](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/734095))。
言語モデルと規則が食い違うセルは、人手監査の優先対象になる。

## 5. 人手でどこまで確認するか

### 5.1 必須の監査

正式58件は全件確認する。ただし、人が正式ラベルを上書きする目的ではない。確認項目は、
レポート原文、言語、公開教師の十二確率、自前教師の状態と根拠、正式ラベル、教師間不一致で
ある。画像を医学的に再判定できない場合も、レポートと教師の対応は監査できる。

正式58件の画像は、少なくとも模型へ入力される画像、断面、左右、切り出し、画質を全件確認
する。病変の有無を非専門家が再ラベル化するのではなく、対象の膝が写っているか、左右や
断面が逆でないか、小病変を潰す縮小になっていないか、中央帯から病変部を外していないかを
見る。

### 5.2 弱ラベル側の推奨標本数

最初の監査は約300検査を目安とする。単純無作為抽出だけではなく、次を重ねて選ぶ。

- 九言語前後を件数に応じて含め、少数言語も最低10件程度確保する。
- 各所見について、陽性、陰性、不確実、記載なしを含める。
- 公開教師と自前教師の差が大きいセルを優先する。
- 0.4から0.6の境界値、0または1に近い高確信例の両方を含める。
- 軽度・少量・疑い・術後・陳旧性・否定・既往を含む報告を優先する。
- 正規化後に同じ報告文となる重複群を確認する。
- 二つの膝を含む検査や、左右情報の解釈が難しい例を含める。

300検査で十二所見すべてを精読すると3,600セルになるため、各検査では全体を眺めつつ、
抽出された根拠と重点所見を中心に500から1,000セルを詳細採点する。誤りが多い所見・言語は
追加で50から100セル監査する。無作為標本の誤り率と、不一致標本の誤り率は分けて記録する。

全4,349件の画像を人手で病変判定する必要はなく、専門家なしにそれを行うと新たな雑音源に
なる。画像の目視は、正式58件と、前処理・左右・系列選択の監査用に各装置指紋から数件、
合計100から200検査程度を先に見るのが現実的である。

### 5.3 監査で保存する指標

- 所見別、言語別の適合率、再現率、AUC
- 陽性、陰性、不確実、記載なしの割合
- 公開教師、自前規則、自前言語モデルの一致率
- 正式ラベルと食い違う理由の分類
- 同一報告文群で出力が一貫しているか
- 人手修正前後の行数、対象識別子、理由、作業者

人手修正した300件だけを高重みで学習すると、選定の偏りを模型へ持ち込む。修正例はまず
教師規則の改善と監査に使い、直接学習へ入れる場合は選定方法と重みを固定する。

## 6. 弱ラベルの学習利用

現在の `p` を教師、`2 × |p - 0.5|` をセル重みとする方式は、記載なしや曖昧な0.5を
損失から除く点で合理的である。ただし次を追加したい。

1. 所見別の教師信頼度を掛ける。正式58件で弱い滑膜炎、急性骨折、外側区画変形性関節症の
   最大重みを下げる。
2. 明示的陰性と記載なしを別に保持する。両方が同じ0.5や0になる表現を避ける。
3. 教師間不一致が大きいセルは重みを下げるか除外する。
4. 同一報告文群が学習と検証へ分かれないよう、正規化報告文のハッシュで群分けする。
5. 外側・内側所見では左右正規化と系列向きを別途監査する。
6. 正式ラベルを画像学習へ使う場合は、弱ラベルより高い重みを与える。ただし後述の外側分割
   では、その分割の正式ラベルを学習へ入れない。

硬い0/1へ変換するより確率教師を使う方向には競技内の支持がある。公開の対応比較では、
強いDINOv2処理で確率教師が硬い教師を三乱数種すべてで上回り、58件の予測集合で+0.0143
だった。ただし対応付き95%区間は-0.0041から+0.0330でゼロをまたいだ。58件では方向性を
示せても、小差を確定できない好例である
([硬い教師と確率教師の比較](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/734105))。

## 7. 58件の正式ラベルによる主検証

### 7.1 固定保留より5分割を選ぶ

正式58件の陽性数は、少ない内側側副靱帯で9件、多い関節液で35件である。20%固定保留では
約12件しかなく、内側側副靱帯陽性は期待値で約2件である。一症例の順位変化が所見AUCを
大きく動かすため、単一固定保留を主評価にするのは不安定である。

五分割なら各回の保留は11または12件だが、全58件が一度ずつ保留予測を持つ。評価時には
五つの保留予測を結合し、58件全体で所見別AUCと十二所見平均AUCを計算する。これにより、
各分割の小さなAUCを平均するより有効標本を使える。

```text
正式58件を多ラベル層化して5群へ固定

第1回: 46/47件 + 弱ラベルで学習 → 第1群を予測
第2回: 46/47件 + 弱ラベルで学習 → 第2群を予測
  ...
第5回: 46/47件 + 弱ラベルで学習 → 第5群を予測
                         ↓
              58件の分割外予測を結合
                         ↓
       所見別AUC、平均AUC、対応付き差の区間
```

五分割作成には多ラベル反復層化を使い、十二所見の陽性数とラベル組合せをなるべく均等に
する。この方法は通常の一列だけの層化より多ラベル問題に適する
([多ラベルデータの層化](https://doi.org/10.1007/978-3-642-23808-6_10))。

### 7.2 群分けの優先順位

同一患者識別子が得られるなら患者単位を最優先する。得られない現状では、少なくとも次を
同じ分割へ置く。

1. 正規化後に同じ読影レポートとなる検査
2. 二膝検査から分けられたと判定できる関連検査
3. 明確な重複画像または再構成系列

装置指紋で58件を完全に群分割すると、群数と陽性分布の制約で層化が崩れる可能性が高い。
そのため、装置・施設外性能は弱ラベル4,349件での副評価とし、正式58件の主5分割では装置
分布を記録して偏りを確認する。可能なら、装置指紋が一群へ集中しすぎない制約を加える。

### 7.3 模型選択と性能推定を分ける

最も厳密には、各外側分割の正式保留群を、指示文調整、弱教師混合、学習停止、模型選択の
すべてから外す。内側では弱ラベル検証集合を使って世代を選ぶか、事前に固定した世代数を
使う。外側の正式予測は最後に一度だけ開く。

一方、現在の実装は全58件を毎世代評価して最良世代を選んでいる。この値は模型選択後の
性能推定として楽観的になる。次の検証改修では、少なくとも各分割の正式保留群で世代選択を
行わないようにする。

## 8. 弱ラベル部分を検証集合にしてよいか

用途を分ければ使ってよいが、主評価には使わない。

| 用途 | 弱ラベル検証 | 正式58件の分割外予測 |
|---|---:|---:|
| 読み込み、損失、前処理の不具合検出 | 適する | 過剰 |
| 教師を画像模型が再現できるか | 適する | 補助 |
| 学習停止時点の候補選択 | 条件付きで適する | 外側保留には使わない |
| 正式画像ラベルに対する性能 | 不適 | 主評価 |
| 教師改善の比較 | 正式ラベルなしでは不適 | 主評価 |
| 装置・言語・報告様式への頑健性 | 副評価として適する | 標本不足 |

弱ラベル検証値が高いことは、画像模型が教師の癖をよく再現したことを示すだけの場合がある。
レポートラベルと画像ラベルには系統差があることが他の放射線画像研究でも示されており、
レポート教師の改善が画像合意ラベル上の模型改善につながる例も報告されている
([画像ラベルとレポートラベルの差](https://arxiv.org/abs/2102.11467)、
[レポートラベル作成器の品質が画像模型へ与える影響](https://arxiv.org/abs/2104.00793))。

競技 Discussion でも、弱ラベル検証と公開順位表の関係が弱く、正式58件は難しい症例または
別分布である可能性が指摘されている。参加者間でも、正式58件と公開順位表が近いという例と、
両者がずれる例の両方がある
([分割外予測と公開順位表の関係](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/736635))。

## 9. 分散、不確実性、非公開順位表への備え

### 9.1 主値と区間

各実験について次を保存する。

- 58件の分割外予測
- 十二所見のAUCと単純平均
- 基準模型との差
- 患者単位の対応付き再標本化を5,000回行った差の95%区間
- 各所見の陽性数と陰性数
- 分割、初期値、入力、教師、重みのハッシュ

再標本化は二つの模型で同じ58件を同時に抽出する。個々の模型の区間より、同じ症例に対する
差の区間を主に見る。二値が片方しか含まれない再標本は、その所見だけ計算不能として扱い、
処理規則を記録する。

小規模医療画像データでは、単一保留の分け方だけでAUCが0.15以上動くことがあり、反復層化
交差検証や再標本化の方が安定するという報告がある
([小標本における性能推定の安定性](https://pubmed.ncbi.nlm.nih.gov/34262098/))。

### 9.2 固定5分割と感度解析

日常の実験比較には、乱数種と割当表を固定した一組の5分割を使う。大きな変更だけ、別の
分割乱数種を用いた5分割を3組程度追加し、分割依存性を確認する。模型初期値の反復と分割の
反復は別に記録する。同じ患者を評価する複数初期値を独立標本として有意差検定してはならない。

### 9.3 判断の目安

- 平均AUC差が0.02未満: 原則未決着。区間、所見別方向、別分割を確認する。
- 0.02以上でも95%区間がゼロをまたぐ: 有望だが未確定。
- 複数分割、複数初期値、公開順位表で方向が揃う: 採用候補。
- 平均だけ改善し、二つ以上の重要所見が大幅悪化: 所見別重みまたは模型混合を検討する。

0.02は理論的閾値ではなく、58件という競技固有の小さな物差しに対する実務上の保守値で
ある。公開ラベル作成者も、58件では0.02未満の差は測定困難としている。

### 9.4 公開順位表を最適化集合にしない

本リポジトリの提出0002から0006では、正式58件の検証と公開順位表は大きな改善では概ね
同方向だった。しかし提出0002から0003では、正式58件が0.57198から0.59087へ上がった一方、
公開スコアは0.595から0.584へ下がった。小差では順位が反転する実例である。

公開順位表は58件より標本数が多い外部確認として有用だが、提出を繰り返して設定を選ぶと
公開部分へ過適合する。提出前に比較仮説と採否条件を記録し、同時に多数案を投げない。
非公開順位表の安定性は、次の三つが揃うほど高くなる。

1. 正式58件の分割外予測で改善する。
2. 別分割・別初期値でも方向が変わらない。
3. 弱ラベルの装置群別副評価でも大きく悪化しない。

## 10. 推奨する二本立ての開発手順

### 系列A: 画像模型の公平な比較

1. 公開 `llm_labels_v4_blend.csv` とそのハッシュを凍結する。
2. 正式58件の多ラベル層化5分割を一度作り、割当表を保存する。
3. 報告文重複を群分けし、各外側保留群を学習と世代選択から外す。
4. 残る正式46または47件を高重み、4,349件を確率教師で学習する。
5. 弱ラベルの内側検証または固定世代で模型を選ぶ。
6. 五つの正式保留予測を結合して主指標を出す。
7. 基準との差を対応付き再標本化区間で判断する。

この系列では教師を変えないため、画像前処理や模型構造の効果を分離できる。

### 系列B: 弱教師の改善

1. 公開教師を基準にし、自前規則と自前多言語言語モデルを追加する。
2. 正式58件を外側5分割し、各保留群を見ずに指示文、所見規則、混合率を決める。
3. 各保留群への教師予測を結合し、教師自身の分割外AUCを計算する。
4. 約300検査の層化監査で、言語別・状態別の誤りを調べる。
5. 改善が0.02以上かつ所見別に説明可能な版だけ、系列Aの教師候補にする。
6. 教師と画像模型を同時に変更せず、まず教師だけを変えた対応実験を行う。

最終提出模型を作る段階では、設計を凍結した後に正式58件すべてを高重みで学習へ戻せる。
ただし、その最終模型には手元の完全に独立した正式評価集合が残らないため、採用判断はそれ以前
の分割外予測で完了させる。

## 11. 直近の実装候補

まだ実験を開始しない前提で、次にコード化するなら順序は次のとおりである。

1. `folds-gold-v1.csv` を作る決定的な多ラベル層化・報告文群分け処理
2. 検査識別子、分割、十二所見、報告文ハッシュ、装置指紋を保存する監査表
3. 五分割の分割外予測を結合して平均AUCと対応付き区間を出す評価処理
4. 弱ラベルを陽性、陰性、不確実、記載なし、根拠へ拡張した表形式
5. 公開教師と自前教師の不一致例を抽出する監査用一覧

分割作成時の受入条件は次のようにする。

- 全58件がちょうど一つの分割へ入る。
- 各分割で十二所見すべてに陽性と陰性が最低一件ずつ存在する。
- 同じ報告文ハッシュが複数分割へまたがらない。
- 各分割の所見別陽性数、装置指紋数、言語数を出力する。
- 分割割当のハッシュを実験記録へ残す。

内側側副靱帯の陽性が9件しかないため、五分割は可能だが余裕が小さい。群制約と両立できず
ある分割で一方のクラスが消える場合は、割当乱数種を人手で順位表へ合わせるのではなく、
「全所見で両クラスを満たす」という事前条件だけで決定的に探索する。
