## 目的

提出0001では正式ラベル58件のうち46件だけを学習に使い、公開スコアは0.526だった。
本提出では画像モデルと画像処理を変えず、公開された読影レポート由来のソフトラベルで
学習検査を1,500件へ増やしたときの効果を確認した。

当初検討したQwen3.5-4Bによる全件ラベル生成は所要時間が長いため中止し、最終的な
提出経路には使用していない。

## 使用データ

- 競技データの `train.csv`、`train_series.csv`、`train_series/` を画像学習に使用した。
- テスト側は `test.csv`、`test_series.csv`、`test_series/` を使用した。
- 外部教師として `stevenleehans/rsna-knee-llm-report-labels` の
  `llm_labels_v4_blend.csv` を使用した。
- 外部教師ファイルのSHA-256は
  `eb4c2b29e7e84adbb4b5ccee825ca20ade6a43dbe295f13be442d549e4f5dca4` だった。
- 外部教師は4,407行、検査識別子と十二所見の13列で、重複、欠損、非有限値、
  0から1の範囲外値がないことを学習前に確認した。
- 競技学習表と外部教師の検査識別子集合が完全一致することも確認した。
- 外部データセットのライセンスはCC0 1.0である。
- 外部の画像事前学習重みは使用していない。

正式ラベルが十二所見すべてに存在する58件は画像モデルの検証専用とし、学習には
使用しなかった。報告文をNFKC正規化し、空白を統一して大文字小文字を畳み込んだ後の
SHA-256が正式58件と一致する候補も除外した。この条件で4件が除外され、4,345件が
擬似ラベル学習候補になった。候補を識別子順へ正規化したうえで、乱数種42により
1,500件を抽出した。抽出識別子集合のSHA-256は
`febb8e0bc67bdc3087dac9ee4c3cb151453b9f759d52afef7f75511c5fc731fe` だった。

## 前処理

画像処理は提出0001から変更していない。各検査で矢状断、冠状断、軸位断ごとに
DICOM数が最大の系列を選び、各断面から決定的に3枚、合計最大9枚を使用した。

各画像へ傾きと切片を反映し、非有限値を有限画素の中央値で置換した。1および99
パーセンタイルで外れ値を抑えて0から1へ正規化し、MONOCHROME1を反転して160×160画素へ
双線形補間した。学習時だけ0.9倍から1.1倍の強度変化を加えた。

## モデル

提出0001と同じ小型多断面畳み込みモデルを乱数初期値から学習した。1チャンネル画像を
24、48、96、160チャンネルの4段の畳み込み符号器へ通し、各画像の160次元特徴を存在する
画像だけで平均した。層正規化、欠落率0.25のドロップアウト、十二出力の全結合層を
適用した。

外部教師の確率 `p` は二値化せず、そのまま二値交差エントロピーの教師値とした。
各セルの信頼度重みを `2 × |p - 0.5|` とし、`p=0.5` のセルは損失から除外した。
項目別正例重みは、信頼度で重み付けした陽性・陰性期待量から求め、0.25から8.0の
範囲に制限した。損失は信頼度重みの合計で正規化し、GPU上で自動混合精度を使用した。

## 結果

公開スコアは **0.595** だった。提出0001の0.526から絶対値で0.069改善し、画像モデルを
変更せずに教師データを増やす仮説を支持した。正式58件の検証AUCも、提出0001の最良値
0.49157から0.57198へ改善した。

## 既知の制約

- 擬似ラベル4,345候補のうち1,500件しか使用していない。
- 外部教師は二つのLLM出力の混合であり、正式な画像所見ではない。
- 外部教師AUCは58件だけから計算しており、項目別推定の分散が大きい。
- SynovitisとFractureは外部教師AUCが約0.79で、他項目より弱い。
- MCLの画像モデル検証AUCは0.28571で、擬似教師の質以外に画像表現上の問題がある。
- DICOMの空間座標を使わず、ファイル名順から画像を選んでいる。
- 断面を区別せず特徴を単純平均し、事前学習済み画像符号器も使用していない。
- 公開スコアの改善が最終非公開テストでも維持される保証はない。

## 次の改善候補

1. 他条件を固定したまま擬似ラベル学習件数を4,345件へ増やす。
2. MCLを中心にDICOMの空間座標を使った中央・連続断面選択を試す。
3. 矢状断、冠状断、軸位断を区別する特徴集約へ変更する。
4. 公開可能な医用画像事前学習符号器を導入する。
5. 複数乱数種または報告文単位の交差検証で改善の不確実性を測る。
