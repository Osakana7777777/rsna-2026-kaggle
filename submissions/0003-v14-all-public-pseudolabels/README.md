## 目的

提出0002では、利用可能な擬似ラベル4,345件から1,500件を抽出して学習し、公開スコア
0.595を得た。本提出では、モデル、画像処理、擬似教師、損失、最適化設定を変えず、
学習対象だけを4,345件すべてへ増やしたときの効果を確認する。

直前の提出から変更した設定は `pseudo_labels.max_studies` のみで、値を1,500から4,345へ
変更した。

## 使用データ

- 競技データの `train.csv`、`train_series.csv`、`train_series/` を画像学習に使用した。
- テスト側は `test.csv`、`test_series.csv`、`test_series/` を使用した。
- 外部教師として `stevenleehans/rsna-knee-llm-report-labels` の
  `llm_labels_v4_blend.csv` を使用した。
- 外部教師ファイルのSHA-256は
  `eb4c2b29e7e84adbb4b5ccee825ca20ade6a43dbe295f13be442d549e4f5dca4` だった。
- 外部教師は4,407行、検査識別子と十二所見の13列で、重複、欠損、非有限値、
  0から1の範囲外値がないことを学習前に確認した。
- 外部データセットのライセンスはCC0 1.0である。
- 外部の画像事前学習重みは使用していない。

正式ラベルが十二所見すべてに存在する58件は検証専用とし、学習には使用しなかった。
正式58件と正規化後の報告文が一致する候補4件も除外した。残った4,345件すべてを学習に
使用し、教師値は合計52,140個だった。学習識別子集合のSHA-256は
`697a1e7e4416726915da13a65d00efa7243ca007f0970b63625dc40720cf06f4` だった。

外部ソフトラベルを正式58件で検証した平均指標は0.89271で、設定した0.88以上の受入条件を
通過した。この検証方法と外部教師自体は提出0002から変更していない。

## 前処理

画像処理は提出0002から変更していない。各検査で矢状断、冠状断、軸位断ごとにDICOM数が
最大の系列を選び、各断面から決定的に3枚、合計最大9枚を使用した。

各画像に傾きと切片を反映し、非有限値を有限画素の中央値で置換した。1および99
パーセンタイルで外れ値を抑えて0から1へ正規化し、`MONOCHROME1`の場合は白黒を反転して
160×160画素へ双線形補間した。学習時だけ画素強度を0.9倍から1.1倍の範囲で変化させた。
左右反転は使用していない。

## モデル

提出0002と同じ小型多断面畳み込みモデルを乱数初期値から学習した。1チャンネル画像を
24、48、96、160チャンネルの4段の畳み込み符号器へ通し、各画像の160次元特徴を存在する
画像だけで平均した。続けて層正規化、欠落率0.25のドロップアウト、十二出力の全結合層を
適用した。矢状断、冠状断、軸位断の特徴は区別せずに平均している。

外部教師の確率を二値化せず、二値交差エントロピーの教師値として使用した。セルごとの
信頼度重みは `2 × |p - 0.5|` とし、`p=0.5` のセルを損失から除外した。項目別正例重みは
信頼度で重み付けした陽性・陰性期待量から求め、0.25から8.0の範囲に制限した。GPU上では
自動混合精度を使用した。

## 結果

公開スコアは **0.584** だった。正式58件の検証値は、学習対象を1,500件から4,345件へ
増やすことで0.57198から0.59087へ改善した一方、公開スコアは提出0002の0.595から
0.011低下した。したがって、同じ擬似教師を全件へ広げるだけでは公開評価の改善に
つながらなかった。検証集合が58件と小さいことによる選択誤差、追加した2,845件の
擬似教師の雑音、または3世代固定による学習条件の不適合が候補として考えられる。

## 既知の制約

- 擬似教師は二つのLLM出力の混合であり、正式な画像所見ではない。
- 外部教師の検証対象は58件だけで、項目別推定の分散が大きい。
- 正式58件をモデル選択にも使用しているため、検証値には選択による偏りがあり得る。
- 学習は3世代だけで、第3世代でも損失が低下していたため、収束を確認できていない。
- DICOMの空間座標を使わず、ファイル名順と決定的な位置ずらしで画像を選んでいる。
- 断面を区別せず特徴を単純平均し、事前学習済み画像符号器も使用していない。
- 単一乱数種の結果であり、公開スコアの差が最終非公開テストでも維持される保証はない。

## 次の改善候補

1. DICOMの空間座標または `InstanceNumber` で画像を解剖学的順序へ並べる。
2. 他条件を固定し、空間的に決定した位置から画像を選ぶ方法を比較する。
3. 断面ごとの画像数を増やし、病変を含む確率を高める。
4. 矢状断、冠状断、軸位断を区別する特徴集約へ変更する。
5. 複数乱数種で学習し、検証値と公開スコアの変動を確認する。
6. 公開可能な医用画像事前学習符号器を導入する。
