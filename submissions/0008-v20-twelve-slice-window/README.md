## 目的

提出0007では、各撮像枠から等間隔に選んだ三枚だけを2.5次元入力へ積み、公開スコアは
0.819だった。本提出では、六枠、系列分類、モデル、教師、最適化条件を固定し、各系列の
中央20～80%を十二枚で広く覆う。学習時は三枚窓を無作為抽出し、検証・推論時は全ての
重なり付き三枚窓を平均することで、局所的な連続性を保ちながら系列内の観察範囲を広げる。

## 前処理

撮像条件分類と六枠構成は提出0007から変更していない。一検査を次の順序で表現した。

1. 矢状断・液体強調・脂肪抑制あり
2. 冠状断・液体強調・脂肪抑制あり
3. 軸位断・液体強調・脂肪抑制あり
4. 矢状断・液体強調・脂肪抑制なし
5. 冠状断・T1強調
6. 矢状断・T1強調

同じ枠に複数候補がある場合はスライス数最大の一系列を選び、同数なら系列識別子の昇順で
決定した。該当系列がない枠は欠損のままとした。各系列はDICOM空間座標で並べ、中央
20～80%から十二枚を等間隔に選んだ。十二枚未満の場合は末尾画像を繰り返した。

画素処理は傾きと切片の反映、非有限値の置換、1および99パーセンタイルでの抑制、0から
1への一枚単位の正規化、`MONOCHROME1` の白黒反転、224×224画素への変更である。
処理済み画像は8ビットへ量子化して `/tmp/rsna2026-dicom-cache` に一時保存し、読み込み時に
単精度の0～1へ戻した。学習時のみ各スライスの強度を0.9倍から1.1倍の範囲で変化させた。

## モデル

各枠の連続三枚を順番どおり三チャンネルへ積み、一つの2.5次元画像として
DINOv2-smallへ入力した。各チャンネルはImageNetの平均と標準偏差で正規化した。
一回の順伝播では六枠それぞれ一窓だけを扱うため、最大DINOv2入力数は提出0007と同じ
六入力である。

DINOv2の分類トークン384次元と画像区画トークン平均384次元を連結し、枠ごとに768次元
特徴を得た。六枠特徴に対する256次元射影、枠埋め込み、十二所見別問い合わせ、欠損
マスク付き注意集約、所見別出力は提出0007と同じである。

総パラメータ数は22,262,668、学習対象パラメータ数は10,858,252である。符号器の出力側
六変換器ブロックと最終層正規化を微調整した。

## 結果

公開スコアは0.863で、提出0007の0.819から0.044、提出0006の0.846から0.017改善し、
現時点の自己最高となった。正式58件の検証AUCも提出0007から0.02453改善しており、
検証と公開採点で改善方向が一致した。系列内の観察範囲を三枚から十二枚へ広げ、推論時に
重なり付き十窓の確率を平均する方法は、本構成において有効だった。

## 既知の制約

- 正式58件を世代選択にも使用しており、検証値には選択による偏りがあり得る。
- 単一乱数種だけで、学習時に選ぶ三枚窓のばらつきを評価していない。
- 学習は四つの非重複窓から一窓だけを使う一方、検証・推論は十窓を使う。
- 十二枚化と同時に一時キャッシュを8ビット化しており、変更効果を完全には分離できない。
- 擬似教師は二つの言語モデル出力の混合で、正式な画像所見ではない。

## 次の改善候補

3. 複数乱数種で、学習窓抽出と最良世代の安定性を確認する。
