## 目的

提出0009では全4分割の最良世代が8、10、9、9であり、最大10世代の終端付近まで学習損失が
低下していた。本提出では分割、画像入力、模型、教師、評価方法を固定したまま、各分割を
20世代まで観測し、収束傾向と分割外評価の変化を調べた。実行時間を抑えるためT4を二枚使う
分散データ並列学習へ変更し、GPUごとのバッチ数を4、全体バッチ数を8とした。線形拡大則に
合わせ、符号器と集約・出力部の学習率をそれぞれ提出0009の2倍にした。

## 前処理

系列選択と画像処理は提出0009から変更していない。矢状断・冠状断・軸位断と撮像条件から
六枠を構成し、同じ枠ではスライス数最大の系列を選んだ。各系列をDICOM空間座標で並べ、
中央20～80%から十二枚を等間隔に選んだ。画素値へ傾きと切片を反映し、1および99
パーセンタイルで抑制して一枚単位で0～1へ正規化した。`MONOCHROME1` は白黒反転し、
224×224画素へ変更した。学習時のみ0.9～1.1倍の強度変化を加えた。

DICOM見出しの全走査を毎回繰り返さないよう、提出0009で得た系列・スライス選択を
`osakanateishoku/rsna-2026-slice-selection-cache` から読み込んだ。選択表のSHA-256は
`8d691f5f58a19f9c0b4196103267844fdb65996b4c0ab29d3749328123b03a75` であり、全検査識別子集合と
選択条件を照合してから使用した。

## モデル

提出0009と同じDINOv2-smallを使用した。各枠の連続三枚を三チャンネルへ積んだ2.5次元画像を
符号器へ入力した。分類トークンと画像区画トークン平均を連結し、六枠特徴を十二所見別
問い合わせによる欠損マスク付き注意集約へ渡した。

総パラメータ数は22,262,668、学習対象パラメータ数は10,858,252である。符号器の出力側
六変換器ブロックと最終層正規化を微調整した。

学習標本は分散標本抽出器でGPU間に分け、世代ごとに乱数種を設定して決定的に並べ替えた。
内側検証と外側評価は重複なく二GPUへ分割し、元の順位を復元してから指標を計算した。学習
損失は全処理の分子と分母を集約した。最良世代の判定と成果物保存は主処理だけが担当し、保存
重みから分散用包みを除いて既存推論との互換性を保った。早期終了は使わず、全分割で20世代を
完了した。

弱ラベルでは教師確率を目標、`2 × |p - 0.5|` をセル重みとした。外側保留でない正式ラベルは
0または1を目標とし、全セルへ3倍重みを与えた。最良世代は提出0009と同じ内側弱ラベルの
十二所見平均AUCで選択した。

## 結果

公開スコアは0.868だった。提出0009の0.853から0.015改善し、それまで最高だった提出0008の
0.863も0.005上回った。分割外平均AUCも提出0009の0.81936から0.83490へ0.01554改善し、公開
スコアの改善方向と一致した。最良世代は12～17となったため、10世代では十分に収束していなかった
という見立てと整合した。二GPU化により、世代数を倍増しながら全体実行時間も短縮できた。ただし、
世代数、全体バッチ数、学習率を同時に変更しており、どの変更が精度改善へ寄与したかは分離できない。

## 既知の制約

- 世代数、全体バッチ数、学習率、分散実装を同時に変えたため、改善への寄与を個別に分離できない。
- 各模型は全体の約60%だけを実学習に使い、内側検証分を最終学習へ戻していない。
- 正式58件の分割外評価には大きな不確実性があり、95%区間は約0.070幅ある。
- 系列選択キャッシュは提出0009の入力集合と処理規則へ固定され、入力変更時は再作成が必要である。
- 内側検証は四つの非重複窓、外側評価と推論は十個の重なり付き窓を使っている。
- 擬似教師は読影レポート由来で、正式な画像所見ではない。

## 次の改善候補

1. 本提出の設定から世代数、全体バッチ数、学習率を一つずつ戻し、改善要因を対応比較する。
2. 分割ごとの最良世代を参考に、内側検証分を戻して約75%のデータで最終模型を再学習する。
3. 外側区画変形性関節症、滑膜炎、外側半月板の入力枠と教師品質を重点的に調べる。
4. 同一チェックポイントで確率平均と順位平均を比較し、統合方式の影響を分離する。
