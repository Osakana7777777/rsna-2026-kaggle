## 目的

提出0010の模型、系列・スライス選択、四分割、教師、学習条件を固定し、画像面内の前処理だけを
全画像の224×224画素への直接変形から、`PixelSpacing`に基づく中央130×130 mm固定物理視野へ
変更した。装置や撮像条件が異なっても、模型へ入る解剖学的尺度を揃える効果を調べた。

EDAの無作為標本200系列では`PixelSpacing`を全件で取得でき、実視野中央値は三断面とも約
160 mmだった。130 mmは各辺の約81%を保持する。元視野が130 mm未満だった軸位断2系列には、
物理尺度を崩さないよう黒余白を加える設計とした。

## 前処理

系列選択とスライス選択は提出0010から変更していない。矢状断・冠状断・軸位断と撮像条件から
六枠を構成し、同じ枠ではスライス数最大の系列を選んだ。各系列をDICOM空間座標で並べ、中央
20～80%から十二枚を等間隔に選んだ。

各画像では傾きと切片を反映し、非有限値を有限画素の中央値で置換した。`PixelSpacing[0]`を
行方向、`PixelSpacing[1]`を列方向として、各方向で130 mmに相当する画素数を四捨五入し、
画像中心から切り出した。元視野が不足する方向には、不足画素を上下または左右へ均等に配置し、
奇数画素の端数は下側または右側へ置いた。

切り出した実画像だけから1および99パーセンタイルを求め、0～1へ正規化した。
`MONOCHROME1`は白黒反転し、その後に値0の余白を加え、224×224画素へ双線形補間した。
画素間隔が欠損、非有限、0以下の場合は復号失敗として既存の欠損マスクへ回す。学習ログでは
この条件による復号失敗は確認されなかった。学習時のみ0.9～1.1倍の強度変化を加えた。

前処理版は `dicom-physical-fov-window-uint8-v3` とし、物理視野を一時キャッシュ識別子と
模型成果物へ含めて、旧キャッシュ利用と学習・推論の設定不一致を防いだ。

## モデル

提出0010と同じDINOv2-smallを使用した。各枠の連続三枚を三チャンネルへ積んだ2.5次元画像を
符号器へ入力した。分類トークンと画像区画トークン平均を連結し、六枠特徴を十二所見別
問い合わせによる欠損マスク付き注意集約へ渡した。

総パラメータ数は22,262,668、学習対象パラメータ数は10,858,252である。符号器の出力側
六変換器ブロックと最終層正規化を微調整した。

## 結果

公開スコアは0.879で、それまで最高だった提出0010の0.868から0.011改善した。一方、分割外
平均AUCは提出0010の0.83490から0.82773へ0.00717低下し、検証と公開採点の方向が一致しなかった。

130 mm固定物理視野は公開評価対象には有効だった可能性があるが、正式58件だけの分割外評価では
その効果を捉えられなかった。対応付き差の95%区間が0をまたぐことから、58件の標本誤差、公開
評価対象との分布差、所見別構成差が不一致へ影響した可能性がある。したがって、公開スコアだけを
根拠に物理視野をさらに狭めず、より多い独立検証例または視野別の追加比較が必要である。

## 既知の制約

- EDAの画素間隔分布は全系列ではなく無作為標本200系列に基づく。
- 画像中心と解剖学的な膝中心のずれを補正していない。
- 全断面・全所見へ同じ130 mmを適用し、所見別・断面別の必要視野を区別していない。
- 正式58件の差の95%区間は0をまたぎ、比較の不確実性が大きい。
- 擬似教師は読影レポート由来で、正式な画像所見ではない。

## 次の改善候補

1. 直接変形を基準に戻し、外側半月板とACLで注意された系列・スライスを可視化する。
2. 140～150 mmのより広い視野、または断面別の物理視野を事前固定して比較する。
3. 固定中心ではなく、膝の解剖学的中心を推定してから切り出す方法を検討する。
4. 滑膜炎と骨挫傷について、130 mmで改善した理由を所見別に調べる。
