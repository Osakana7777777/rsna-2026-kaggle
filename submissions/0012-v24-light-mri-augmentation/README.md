## 目的

提出0011のデータ、中央130 mm固定物理視野、模型、四分割、教師、学習条件を固定し、
学習時だけMRI向けの軽い面内幾何変換、強度変換、雑音、ぼかしを追加した。
装置、撮像条件、患者位置の小さな差に対する頑健性が向上するかを確認する。

2.5次元入力を構成する同一撮像系列の三枚には、幾何変換と強度変換の乱数を共有した。
左右反転、上下反転、スライス標本化の変更、撮像系列欠落、弾性変形は使用していない。

## 前処理

六つの撮像枠を使用し、同じ枠ではスライス数最大の系列を選んだ。各系列をDICOM空間座標で
並べ、中央20～80%から十二枚を等間隔に選んだ。各画像では傾きと切片を反映し、非有限値を
有限画素の中央値で置換した。

`PixelSpacing`に基づいて画像中心から130×130 mmを切り出し、不足部分は値0で埋めた。
切り出した実画像の1および99パーセンタイルで0～1へ正規化し、`MONOCHROME1`を反転して
224×224画素へ双線形補間した。固定前処理版は
`dicom-physical-fov-window-uint8-v3` のままとした。

学習時は三枚窓を一つの三チャンネル画像へまとめた後、撮像系列ごとに独立して次を適用した。

| 変換 | 範囲 | 確率 |
|---|---:|---:|
| 回転 | ±8度 | 0.5 |
| 平行移動・拡縮 | 縦横±5%、0.92～1.08倍 | 0.5 |
| 明るさ・コントラスト | 各±10% | 0.4 |
| ガンマ | 0.85～1.15 | 0.3 |
| ガウス雑音 | 標準偏差0～0.02 | 0.2 |
| ガウスぼかし | 核3または5、標準偏差0.1～1.0 | 0.1 |

幾何変換、明るさ、コントラスト、ガンマ、ぼかしの値は同一撮像系列の三枚で共有した。
雑音は適用判定と標準偏差を共有し、画素ごとの雑音だけ独立に生成した。幾何変換の外側と
欠損スライスは値0とし、最終値を0～1へ制限した。検証と推論では画像拡張を適用していない。

## モデル

提出0011と同じDINOv2-smallを使用した。各撮像枠の連続三枚を三チャンネルへ積んで符号器へ
入力し、分類トークンと画像区画トークン平均を連結した。六枠の特徴は十二所見別問い合わせに
よる欠損マスク付き注意集約へ渡した。

総パラメータ数は22,262,668、学習対象パラメータ数は10,858,252である。符号器の出力側
六変換器ブロックと最終層正規化を微調整した。

## 結果

公開スコアは0.879で、提出0011と同点だった。分割外平均AUCは提出0011から0.00183低下した
ため、今回の軽量画像拡張による一貫した改善は確認できなかった。一方、公開評価を悪化させずに
頑健化を追加できた可能性はある。所見別ではMCL、外側区画変形性関節症、急性骨折などが改善し、
内側半月板、膝蓋大腿区画変形性関節症、滑膜炎、骨挫傷が低下した。

分割外評価と公開評価で大きな方向不一致はなく、どちらも提出0011に対してほぼ横ばいだった。
ただし公開スコアは小数第3位までしか得られないため、小さな差の有無は判断できない。

## 既知の制約

- 正式ラベルは58検査だけで、所見別の差は標本誤差の影響を強く受ける。
- 六種類の拡張を同時に追加したため、個別変換の寄与は分離できない。
- 全断面・全所見へ同じ拡張範囲を使用し、断面ごとの適切な強度を検証していない。
- 提出0011との差に対する対応付き再標本化区間を算出できない。
- 公開スコアは小数第3位までで、提出0011との微小な差を比較できない。

## 次の改善候補

1. 強度変換だけ、幾何変換だけの分離比較を行う。
2. 内側半月板、膝蓋大腿区画変形性関節症、滑膜炎で悪化した変換を断面別に調べる。
3. 拡張確率または範囲を半減し、現在の設定が強すぎないか確認する。
4. 画像拡張を固定した後、スライス位置揺らぎと撮像系列欠落を独立に評価する。
