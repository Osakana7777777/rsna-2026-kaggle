## 目的

提出0012の224画素、中央130 mm固定物理視野、六撮像枠、画像拡張、弱教師、正式4分割を
基準とし、系列全体を物理的に覆う十個の三枚窓を一度に模型へ入力する。所見別の窓注意集約と
撮像枠注意集約により、従来の推論後確率平均より表現力の高い階層集約になるか確認する。

## 前処理

矢状断液体強調脂肪抑制、冠状断液体強調脂肪抑制、軸位断液体強調脂肪抑制、矢状断液体強調
非脂肪抑制、冠状断T1、矢状断T1の六枠を使用した。同じ枠に複数系列がある場合は
スライス数最大の系列を選んだ。

各系列の全DICOMについて、`ImageOrientationPatient`から求めた法線へ
`ImagePositionPatient`を射影して物理順に並べた。元画像上で連続する三枚を候補窓とし、候補範囲へ
十個の目標中心を等間隔に置いた。目標との物理距離の総和が最小になる、単調かつ重複しない
十窓を選択した。候補が十個未満の場合は各候補を一度だけ使い、残りを欠損とした。幾何情報が
不正な系列は相対添字へ戻さず撮像枠全体を欠損とした。学習全体では有効窓200,709個、欠損枠は
撮像枠別に288、197、64、1,647、1,580、2,595件だった。幾何不正、大間隔、重複座標の記録は
いずれも0件だった。

各画像では傾きと切片を反映し、画像中心から130×130 mmを切り出した。不足部分は値0で埋め、
実画像部分の1および99パーセンタイルで0～1へ正規化した。`MONOCHROME1`を反転し、
224×224画素へ双線形補間した。固定前処理版は
`dicom-physical-fov-window-uint8-v4`である。同じ元画像が複数窓に現れる場合は一度だけ復号し、
検査単位の一時キャッシュへ8ビットで保存した。

学習時は同じ撮像枠の全十窓で乱数を共有した。回転は±8度、平行移動は縦横±5%、拡縮は
0.92～1.08倍、明るさとコントラストは各±10%、ガンマは0.85～1.15、ガウス雑音は標準偏差
0～0.02、ガウスぼかしは核3または5とした。検証と推論では画像拡張を適用していない。

## モデル

共有DINOv2-smallへ有効窓だけをまとめて入力し、分類トークンと画像区画トークン平均を連結した
768次元特徴を検査、六枠、十窓の配置へ戻した。物理相対位置、前方間隔÷系列中央値、後方間隔÷
系列中央値の三特徴を多層写像で加えた。

十二所見別問い合わせにより各撮像枠内の十窓を欠損マスク付き軟注意で256次元へ集約し、続いて
所見別に六撮像枠を軟注意で集約して十二ロジットを出力した。総パラメータ数は22,333,068、
学習対象パラメータ数は10,928,652である。DINOv2の出力側六変換器ブロックと最終層正規化を
微調整し、勾配検査点機能を有効にした。

外側保留58検査の注意成果物を監査した。欠損窓と欠損撮像枠の最大重みは厳密に0、有効要素の
重み和と1との差は最大`1.79e-7`だった。

## 結果

公開スコアは0.897で、提出0013の0.881から0.016、基準とした提出0012の0.879から0.018
改善した。分割外平均AUCも提出0012の0.82590から0.84371へ0.01781改善しており、公開評価と
改善方向および大きさがよく一致した。物理座標で系列全体を覆う密窓と所見別二段注意集約は、
今回の差分では有効だった。

所見別では内側半月板、膝蓋大腿区画変形性関節症、骨挫傷、外側半月板で比較的大きな改善が
あり、関節液は0.08571低下した。平均値の改善だけでなく、注意成果物を使って関節液の低下を
調べる必要がある。

## 既知の制約

- 正式ラベルは58検査だけで、所見別の差は標本誤差の影響を強く受ける。
- 提出0012との差に対する対応付き再標本化区間を算出できない。
- 複数系列保持、左右統一、撮像枠再分類、医学的な注意事前分布は導入していない。
- 関節液、滑膜炎、ベーカー嚢胞、急性骨折の分割外AUCは提出0012より低い。
- 一時画像キャッシュはKaggle実行間では保持されず、初回世代で約55万枚のDICOM復号が発生する。
- 通常推論で見えるテストは3検査だけなので、提出値は百分位順位平均により粗い値となる。

## 次の改善候補

1. 公開スコアと所見別挙動を確認し、密窓階層集約を後続実験の基準にするか判断する。
2. 関節液で低下した原因を窓注意・撮像枠注意から調べる。
3. 公開実装`dicomsdl`を転送構文別に比較し、画素一致を確認した上で初回復号を高速化する。
4. 左右統一、撮像枠再分類、複数系列保持を一変更ずつ検証する。
