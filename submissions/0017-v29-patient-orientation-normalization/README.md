## 目的

冠状断と軸位断で膝の内側が画像右側となるよう患者座標から正規化し、模型が内外側の
画素上の左右位置を別々に学ぶ負担を減らす。DICOMの左右タグと幾何判定の不一致も監査する。
提出0016を基準とし、撮像枠、系列選択、模型、弱教師、分割、画像拡張、学習率、世代数は
維持して、患者座標による左右正規化だけを追加した効果を確認する。

## 前処理

`ImageOrientationPatient`、`ImagePositionPatient`、`PixelSpacing`から画素4隅の患者座標を求め、
左右を幾何判定した。`Laterality`も参照し、不一致時は幾何判定を正規化に採用して監査対象とした。
冠状断・軸位断は、判定した内側が画像右となるために必要な場合だけ水平反転し、矢状断は
反転しない。幾何判定不能時は有効な`Laterality`を採用し、両方から判定できない場合は反転しない。

前処理版は`dicom-physical-fov-window-orientation-uint8-v5`である。四つの永続キャッシュは
前処理ノートブック版2の出力を使用した。この「版2」はKaggleノートブックの版番号であり、
各マニフェストが宣言する前処理版は上記の`v5`である。固定したマニフェストSHA-256はshard順に
次のとおりである。

1. `432466d2ceabeefad9b8c77169fdd357d92def685dc637a9d7360a6c63d301f4`
2. `27c0bef3bd2c7614bf1aba0d8bd63831c5744c997a13e34776732568846da737`
3. `55a5a90a40064230120210b5f0a9e9a24af074404d9ef65267855d914dad0d45`
4. `e89b0cc5a6c1ba7ad9bd68bae46ff32dc1df0ac90d3a79557d6ffe932763c481`

全665,954枚のうち665,952枚を復号し、既知の2枚は失敗フラグを維持した。
左右監査は24,371系列で実施した。左右の採用元は幾何17,488系列、DICOMタグ3,906系列、
判定不能2,977系列で、5,407系列を水平反転した。断面判定は矢状9,857、冠状8,463、
軸位5,878、斜位173系列だった。タグ・幾何不一致は158系列、該当検査は80件だった。

中央130 mm、1・99百分位正規化、`MONOCHROME1`反転、224画素双線形補間、系列ごとの最大十個の
物理座標連続三枚窓、および提出0016と同一の同期画像拡張を用いた。
採用系列は21,334本、学習で参照したキャッシュ画像経路は重複を除いて588,266件だった。
学習選択記録SHA-256は
`5d639d8a41b4001b0eed8398e6a3a2cdc680eb06cb025a3a24695cc6cc26eb01`である。

## モデル

DINOv2-smallを三枚2.5次元入力へ適用し、所見別の窓・系列・撮像枠注意で12所見を集約した。
総パラメータ数は22,402,444、学習対象は10,998,028である。四分割模型の所見別百分位順位を平均して
推論値を作成した。符号器の最後の六変換器ブロックと最終層正規化を微調整し、物理相対位置と
前後間隔特徴を注意集約へ入力した。欠損窓・系列・撮像枠はマスクした。

## 学習

4分割交差検証、乱数種42～45、各分割20世代、Tesla T4二枚、GPUごとのバッチ数1、勾配蓄積4で
実効バッチ数8とした。AdamW、符号器学習率0.000016、集約・出力部学習率0.002、重み減衰0.02、
一周期方式の立ち上がり比率0.15を使用した。最良世代は内側弱ラベルの平均AUCで選択した。
各模型の実学習数は2,651～2,654検査、内側弱ラベル検証数は651～653検査である。弱ラベルは
教師確率を目標とし、`2 × |p - 0.5|`をセル重みとした。外側保留以外の正式ラベルは0または1を
目標とし、損失重みを3倍にした。

## 結果

提出識別子56204959の公開スコアは0.897で完了した。基準の提出0016の0.899を0.002下回り、
提出0014の0.897と同値だった。一方、分割外マクロAUCは提出0016から0.00972上昇した。ACL、
関節液、滑膜炎、骨挫傷の分割外AUC改善が大きい一方、外側区画変形性関節症、膝蓋大腿区画
変形性関節症、急性骨折は低下した。

小規模な正式ラベル検証と公開評価の方向が一致しなかったため、今回の結果だけでは左右正規化を
有効とは判断しない。後続実験の基準には採用せず、不一致系列と判定不能系列の扱いを分離した
追加検証を優先する。

## 既知の制約

- 左右の幾何判定は患者座標X=0を正中基準とし、画像の画素中心範囲全体がX>0なら左膝、X<0なら右膝とする。
- タグ・幾何不一致の158系列を除外せず、幾何判定で正規化している。臨床的妥当性の個別確認は未実施である。
- 左右を判定できない2,977系列と斜位173系列は水平反転の対象外であり、全系列の向きが統一されたわけではない。
- 正式ラベルは58検査のみで、分割外指標の差を小さな改善まで断定できない。
- 通常推論で見える試験画像は3検査のみで、順位平均の値が粗い。

## 次の改善候補

1. 80件の不一致検査を監査し、タグと患者座標のどちらが不正確かを分類する。
2. 判定不能2,977系列を除外する場合と未反転で残す場合を比較する。
3. 不一致系列の除外・幾何優先・タグ優先を分け、同じ分割で再検証する。
