## 前処理

前処理版は`dicom-physical-fov-window-orientation-uint8-v5`である。患者座標により冠状断・軸位断を
正規化し、内側が画像右側となるよう必要時だけ水平反転する。中央130 mmを切り出し、1・99百分位
正規化、`MONOCHROME1`反転、224画素双線形補間を行った。各系列から物理座標連続の三枚窓を最大十個
抽出し、位置特徴として物理相対位置、前方間隔/中央値、後方間隔/中央値を使用した。

四つの永続キャッシュは提出0017と同じで、合計665,954枚中665,952枚を復号し、既知の2枚は失敗
フラグのまま扱った。採用系列は21,334本、学習で参照したキャッシュ画像経路は重複を除いて588,266件
だった。学習選択記録SHA-256は
`5d639d8a41b4001b0eed8398e6a3a2cdc680eb06cb025a3a24695cc6cc26eb01`である。

## モデル

DINOv2-smallを三枚2.5次元入力へ適用した。全6撮像枠×最大1系列×10 windowの埋め込みを平坦化し、
特徴・物理位置・学習可能な撮像枠埋め込みを256次元へ射影した。8ヘッドのpre-normalization自己注意
残差層を2層適用し（FFNなし）、その後に12所見ごとのqueryによるglobal masked attentionでlogitを
出力した。欠損windowはkey/valueとpoolingから除外した。

総パラメータ数は22,791,564、学習対象は11,387,148である。注意重み成果物はwindow、series、slotの
従来形状を維持するが、seriesとslotはglobal window attentionの周辺和であり、旧階層注意の独立softmax
ではない。四分割模型の所見別百分位順位を平均して推論値を作成した。

## 学習

4分割交差検証、乱数種42～45、各分割20世代、Tesla T4二枚、GPUごとのバッチ数1、勾配蓄積4で
実効バッチ数8とした。AdamW、符号器学習率0.000016、集約・出力部学習率0.002、重み減衰0.02、
一周期方式の立ち上がり比率0.15を使用した。最良世代は内側弱ラベルの平均AUCで選択した。
各模型の実学習数は2,651～2,654検査、内側弱ラベル検証数は651～653検査である。弱ラベルは教師確率を
目標とし、`2 × |p - 0.5|`をセル重みとした。外側保留以外の正式ラベルは0または1を目標とし、損失重みを
3倍にした。

## 結果

提出識別子56251825の公開スコアは0.893で完了した。提出0017の0.897を0.004下回った。
分割外マクロAUCは提出0017より0.00109高かったが、公開評価では改善が再現されなかったため、
今回の2層Transformer MILを有効とは判断しない。

## 既知の制約

- 正式ラベルは58検査のみであり、分割外AUCの0.00109差を小さな改善まで判断できない。
- testは3検査のみで、所見別百分位順位平均の出力値は粗い。
- full self-attentionの計算量はwindow token数の二乗に比例する。今回は60 tokenで問題ないが、窓数や
  系列数を増やす場合は再評価が必要である。
- 注意重みのseries/slotはglobal attentionの周辺和であり、旧階層モデルの段階的な注意と同じ意味ではない。

## 次の改善候補

1. self-attention層数、head数、FFN追加を一要因ずつ比較する。
2. 疾患別target token方式を、現在のglobal query poolingと同じ分割で比較する。
3. 階層注意とTransformer MILの出力校正・所見別AUC差を同じ外側分割で分析する。
