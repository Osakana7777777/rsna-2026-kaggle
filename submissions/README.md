# 提出記録

Kaggleへ正式提出した実験を、提出単位で保存する。各提出は
`<連番>-v<Kaggle版番号>-<短い名称>/README.md` に記録する。

## 一覧

| 連番 | Kaggle版 | 提出日時（日本時間） | 概要 | 公開スコア | 状態 |
|---:|---:|---|---|---:|---|
| 0001 | 12 | 2026-08-22 19:51 | 小型多断面畳み込みモデル | 0.526 | 完了 |

## 記録の手順

1. 実験設定とコードを確定する。
2. `./scripts/verify.sh` を実行する。
3. `./scripts/push.sh` でKaggle版を作成し、版番号を控える。
4. `./scripts/wait.sh` と `./scripts/output.sh` を実行する。
5. `TEMPLATE.md` を複製し、設定、処理、検証結果、既知の制約を記入する。
6. コード競技として正式提出する。
7. `kaggle competitions submissions` で状態と公開スコアを確認し、記録を更新する。

失敗したKaggle実行は正式提出の連番に含めない。ただし、提出方法や実装上の重要な
知見が得られた場合は、対応する正式提出の「実行・提出基盤」へ記載する。
